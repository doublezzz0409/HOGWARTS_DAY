## 1. 定位与本质

WF-03 是一个**由导演控制加工范围与生成策略的专业提示词加工 Agent**：
- 输入：WF-02 正式导演稿（FINAL）+ 两份 Skill 原文。
- 输出：**可直接用于视频生成工具的完整提示词** + 参考素材引用 + 生成任务对应关系 + 质检结果。
- 本质：**不是固定顺序自动流水线**，而是"主 Agent 按导演每次指定的范围与策略，忠实把导演意图转成模型可执行描述"。

## 2. 架构（单主 Agent）

- **一个主 Agent 独立完成**：理解导演意图 → 读取 Skill → 加工提示词 → 质量检查 → 成果交付 → 持久化。
- **不设常驻 Subagent 团队；不拆分多个 Agent 分别写提示词。**
- **不依赖** `workflow` 工具、Subagent 或自动审批能力（均未在本项目验证；本工作流**不使用**）。
- 加工范围由导演每次指定（整 SC / 单 SH / 指定多 SH / 指定时长任务），**不写死顺序**（可不按 SC01→SC02 顺序）。

## 4. 导演指令接口（每次由导演指定，Agent 不写死）

导演需（可一次给多镜）指定：
1. **加工范围**：整 SC / 单 SH / 指定多个 SH / 以具体生成任务为单位。粒度由导演定。
2. **每镜视频时长**：逐 SH 或逐生成任务给出（秒）。时长处理见 **§4.1 时长规则（权威）**：导演已给则严格遵守；未给则按 §4.1 判断（可自主或停问），**不机械停问**。
3. **生成策略**：纯文字（T2V）/ 参考图（R2V）/ 首尾帧 / 多参考 / 混合；粒度可在 SC 级 / SH 级 / 任务级。Agent **不得擅自改变**。
4. **其他要求**：画幅/宽高比、风格、禁止项、参考素材指定等。

若导演指令**缺少关键决策**（如**无生成策略**且无法默认、或**时长缺失且按 §4.1 属"实质影响"**）、或**导演设计与策略实质冲突/无法执行**：**说明问题并停问导演**，不得自行替导演决定。（**时长缺失一般不停问**，见 §4.1。）

### 4.1 时长规则（权威）

> 本节是 WF-03 **时长处理的唯一权威规则**；§4-2、§5-Step0、§7-1、§8、§12 的时长表述均引用本节，**不重复定义**。

1. **导演明确指定时长：严格遵守，不得擅自改变。**
2. **导演未指定、但不影响当前提示词设计与任务拆分：Agent 自主判断并继续，不机械停问。**（默认按导演稿既有"节奏·时长约值"与体验节奏合理取值，记入任务卡，**不作为导演决定**。）
3. **时长会实质影响镜头设计、提示词组织或生成任务拆分、且现有信息无法合理判断：暂停并向导演询问。**（例：需据此决定"单镜 vs 多片段切分"，或模型时长硬限制下需裁切导演意图。）
4. **可以提出时长建议，但必须明确标注为 `[Agent 建议]`，不得当作导演决定。**
5. **不得因时长未指定，就擅自改变导演指定的生成策略或镜头意图。**

> 判定要点：区分"**不影响设计的时长**（可自主）"与"**决定任务拆分的时长**（缺则停问）。不能确定是否实质影响时，按"实质影响"从谨慎处理（停问）。

## 5. 执行流程（单主 Agent，逐步）

- **Step 0 任务接收与参数确认**：解析导演指令 → 明确"加工范围/时长/策略/参考素材/其他"。缺关键项按 §4（策略）与 §4.1（时长）判断：策略缺失且无法默认→停问；时长缺失按 §4.1（可自主则继续并标注）；其余可自主并标注。
- **Step 1 读取三项强制输入**：读 FINAL（对应集）＋ ACTING ＋ CINEDANCE 全文（§3）。记录已读。
- **Step 2 读取加工范围内上下文**：读 FINAL 中目标 SC/SH 的完整字段（功能/主体·动作/景别视角构图/摄影机运动/时长/焦点/光色声/衔接连续性/锁定允许/参考需求）＋相邻 SH 以保连续性＋SC 整体体验。
- **Step 3 逐 SH 加工（在导演指定范围内）**：
  - 以 **CINEDANCE** 装配提示词（按其分节：场景/参考/地点图/首帧与空间调度/格式模式/光学/相机/动作时间/物理/光线/声音/正向约束；用可测语言与物理行为）。
  - 以 **ACTING** 写表演层（仅对画面内角色；`objective/obstacle/tactics/beats/eye life/voice` 等，按其规则；**纯 POV 无人在画时不得编造人物表演**）。
  - **忠实于导演稿**：不改镜头功能/核心动作/情绪/叙事意图/构图与运镜意图；不"为更好看"重创镜头。
- **Step 4 生成策略组织**：按导演策略组织（如 R2V 需绑定真实参考图；首尾帧需定义首帧与末帧状态；多片段需各自成段）。
- **Step 5 质量检查**（§8）：对照导演稿意图 + Skill + 策略/时长 + 参考素材真实性 + 连续性 + 可执行性；可自修则修后复核。
- **Step 6 交付**（§6/§7）：参考素材引用 + 完整提示词 + 生成任务对应关系 + 质检结果。
- **Step 7 持久化**（§9）：保存成果文件 + 版本/状态。

## 6. 参考素材管理

- **必须写明实际文件名 + 项目相对路径**；**不得虚构**文件名/路径。
- **无参考图需求**：明确标注"**本任务无需参考图**"。
- **缺少必要素材**：明确指出**缺失**（当前项目**无角色/地点/道具参考资产**，`assets/` 为空——须如实标缺失，不得假定存在）。
- 多个 SH 可共用参考素材，但**必须写明引用关系**。
- 参考图仅在其**真实存在**时才可被引用；否则提示词须相应降级（如改为纯文字描述）并标注由导演确认。

## 7. 提示词交付规范

1. **完整提示词**（不是思路/大纲/半成品），符合导演指定**策略与时长**；时长按 §4.1：导演已定→严格遵守，Agent 自主判断→标注 `[Agent 建议]`。
2. **一个 SH 需拆多个生成片段**时，**分别提供**对应提示词并各自标明时长/策略。
3. **生成任务对应关系**：明确 `SC → SH → 生成任务(片段) → 提示词` 的映射；**不得默认"一 SH＝一生成片段"**。
4. 附**质检结果**（§8）与**未解决问题**。

## 8. 质量检查清单（每次交付前必检）

- [ ] 忠实保留导演稿的**镜头功能 / 主体 / 动作 / 构图 / 运镜 / 情绪 / 连续性意图**
- [ ] 正确应用 **ACTING + CINEDANCE** 相关要求（表演层仅对画内角色；纯 POV 不编造表演）
- [ ] 符合**导演指定的生成策略与时长**（时长按 §4.1：已定则严格遵守；自主判断须标 `[Agent 建议]`；实质影响且无法判断须已停问）
- [ ] 参考素材**文件名/路径/引用关系真实准确**（或如实标"无需/缺失"）
- [ ] 提示词**完整、清晰、可直接生成**
- [ ] 无**空间/动作/人物/视觉连续性冲突**（跨 SH）
- [ ] 无**遗漏、自相矛盾、模型难以执行**的描述
- 可自修→修正后重检；不可自修（缺决策/策略冲突/素材缺失致不可执行）→ **明确反馈导演**。

## 10. 状态与验收（不伪装）

- 采用 `PROJECT_RULES §4.4` 三维：**执行状态 / 验收状态(六值：草稿·待提交·已提交导演·已批准·需修改·已锁定) / 持久化状态**。
- 提示词成果：生成=**草稿**；提交导演=**已提交导演**；导演接受=**已批准**；锁定=**已锁定**。
- **不得把未验收成果伪装成正式验收成果**；保留版本与状态。
- 单次加工成果可独立记录与验收，不强制先完成整 SC。

## 11. 不可越权（硬约束）

- 不擅自改变导演指定**生成策略**；不改导演稿**核心动作/镜头功能/情绪/叙事意图**；不为"更好看"**重创镜头**；**纯 POV 不编造人物表演**。
- 发现设计/策略**实质冲突、缺关键决策、无法执行** → **说明并停问导演**；可提技术建议，但不替导演做重大决定。
- 不改 DSH 底层配置；不改 WF-01/WF-02 既有成果；不越级进入其他工作流职责。
