# HOGWARTS_DAY

### 可复用的第一人称世界体验叙事工作流

**English** · [中文](#) · [Read the English version →](README.md)

**让观众不只是观看一个世界，而是想要生活在其中。**

HOGWARTS_DAY 是一套可复用的创意工作流，用于设计第一人称世界体验故事与沉浸式短视频。

它探索如何把一个虚构世界中的地点、活动、日常与情感体验，转化为引人入胜的视听作品，让观众产生"若能走进那个世界该多好"的向往。

---

## ✨ 愿景

是什么让观众爱上一个虚构世界？

不只是壮丽的风景、奇异的生物，或强大的魔力。

而是一种感觉：那个世界里，正有一种生活等着他们去经历。

一个可以去的地方。
一段可以去体验的日常。
一个值得记住的小小发现。
一个可以一起消磨时光的人。
一个让人不愿离开的世界。

HOGWARTS_DAY 围绕一个核心创意追求而构建：

> **让观众想要住进他们刚刚看过的那个世界。**

目标不是简单呈现一堆漂亮的镜头，而是设计出让观众能够把自己想象成参与者、而非远处旁观者的体验。

## 🎯 核心体验设计

本项目探索一段四阶段的观众旅程：

**认识 → 体验 → 连接 → 渴望**

| 阶段 | 创意目标 |
|---|---|
| 认识 | 呈现一个独特、值得探索的世界。 |
| 体验 | 让观众想象自己参与到它日常的活动与非凡的时刻之中。 |
| 连接 | 通过日常、关系与细节建立情感依恋。 |
| 渴望 | 让观众希望自己能留下、去体验更多。 |

三个创意维度支撑这段旅程：

- **世界奇观：** 什么让观众停下脚步、驻足凝视？
- **独特体验：** 什么让观众想要亲身参与？
- **生活与情感：** 什么让观众想要留下？

## 🧭 工作流

HOGWARTS_DAY 采用分阶段创意工作流。每个阶段都有明确的职责与交付物。

| 工作流 | 职责 |
|---|---|
| WF-00 · 项目初始化与任务分流 | 确立项目背景、约束与任务归属。 |
| WF-01 · 世界生活研究 | 考察世界的原著事实、日常生活、活动、地点与体验机会。 |
| WF-02 · 创意策划 | 制定整体创意方向与体验策略。 |
| WF-03 · 场景开发 | 通过迭代式创意评审与批准来设计单个场景。 |
| WF-04 · 导演整合 | 将已批准的场景连接为连贯的视听体验。 |
| WF-05 · 制作与复盘 | 准备制作、评估结果，并将洞见反馈回工作流。 |

### WF-01 与 WF-02 的边界

研究与策划之间的职责划分是刻意的、清晰的：

- **WF-01** 负责弄清楚：这个世界里有什么值得体验。
- **WF-02** 负责决定：我们要带观众体验什么，以及如何把这些体验组织成一个有吸引力的整体。

简言之：WF-01 找出有哪些体验可做，WF-02 选定要体验什么、并决定如何组织。

### WF-02 多维创意决策地图

> 这是后续研究的覆盖清单，不是已经确定的评分表。

**01. 观众吸引力**

- 是否能激发好奇？
- 是否具有广泛的兴趣基础？
- 是否有独特、清晰的观看承诺？
- 是否能让不同背景的观众理解？

**02. 体验价值**

- 观众究竟能体验到什么？
- 是观看、参与、探索，还是获得某种身份？
- 有没有现实世界无法提供的体验？
- 是否产生「我也想亲自经历」的欲望？

**03. 世界独特性**

- 是否充分体现这个世界的独有规则？
- 是否只是普通生活换了一套魔法皮肤？
- 是否展示了世界不为人知的一面？
- 是否符合原著和世界观依据？

**04. 情绪与心理连接**

- 是否产生惊叹、快乐、温暖、好奇或放松？
- 是否产生归属感？
- 是否让观众向往这里的生活？
- 是否形成情绪上的记忆点？

**05. 体验之间的关系**

- 几个体验能否相互连接？
- 是否有先后顺序和因果关系？
- 是否重复表达同一种价值？
- 组合后是否产生单独体验不具备的新价值？

**06. 整体叙事与节奏**

- 一天是否有完整的体验弧线？
- 是否有开场、发展、高潮和结束？
- 是否存在无聊、拥挤或断裂的部分？
- 是否有足够的变化和期待？

**07. 注意力与传播**

- 如何吸引点击？
- 如何持续提供观看理由？
- 如何设置信息释放和惊喜？
- 如何兑现开头的承诺？
- 是否具有分享和讨论价值？

**08. 制作与实现**

- AI 是否能可靠实现？
- 人物、空间、魔法是否容易漂移？
- 是否需要参考图或复杂连续镜头？
- 制作成本与收益是否合理？
- 是否存在版权、事实或安全问题？

**09. 系列化与长期价值**

- 是否能形成系列特色？
- 是否有其他世界或地点可以延伸？
- 是否容易让观众期待下一集？
- 是否帮助建立独特的频道品牌？

### WF-02 模块研究贡献与完成程度

| 模块 | 当前研究贡献 | 完成程度 |
|---|---|---|
| 模块 0：研究基础与问题地图 | 建立了部分创意问题分类、事实边界和研究边界 | 部分覆盖 |
| 模块 1：创意生成机制 | 创意来源、创意变形、跨领域迁移、概念深化 | 已有阶段成果 |
| 模块 2：体验价值与筛选机制 | 建立多维评价的必要性和初步问题意识 | 尚未解决 |
| 模块 3：体验组合与整体结构 | 认识到单项精彩不等于整体价值 | 尚未解决 |
| 模块 4：观众注意力与体验兑现 | 区分传播吸引力与真实体验价值 | 尚未解决 |
| 模块 5：制作约束与质量验证 | 初步明确创意价值与制作可行性分离 | 尚未解决 |
| 模块 6：整合、案例验证与方法迁移 | 有过单视频创意生成压力测试，但未完成整个决策体系验证 | 尚未解决 |

### 受控的创意流程

工作流强调明确的决策与阶段边界：

- 先研究，再策划。
- 先观众体验，再镜头设计。
- 逐个开发、评审、修改、批准各场景。
- 保持"已核实资料"与"创意诠释"之间的界线。
- 不把建议当作已批准的决策。
- 未满足所需条件，不得推进阶段。

最终创意决定权归导演。AI 代理在明确划定的边界内，协助研究、分析、策划、文档与制作任务。

## 🏗️ 架构

项目把可复用的工作流规则与世界专属知识分离。

```text
HOGWARTS_DAY/
│
├── core/           # 可复用的工作流基础
├── world/          # 世界专属知识
│   ├── canon/      # 原著事实与原始资料
│   ├── experience/ # 世界体验与研究结果
│   └── references/ # 辅助参考资料
│
├── planning/       # 创意策划
├── scenes/         # 单个场景开发
├── director/       # 导演层面的整合
├── production/     # 制作素材
├── reviews/        # 评审与复盘
├── assets/         # 已批准的、可复用的创意素材
│
├── AGENTS.md
├── PROJECT_RULES.md
├── PROJECT_STATE.md
├── WORKFLOW_SPEC.md
└── DECISION_LOG.md
```

架构设计旨在让两类知识保持区分：

**可复用的工作流知识**

方法、流程、决策规则、评审标准与协作协议——可跨不同虚构世界复用。

**世界专属知识**

属于某一特定世界的原著事实、地点、角色、活动、参考资料与已批准的体验设计。

这种分离意在让工作流可以超越霍格沃茨、适用于更广的世界。

## 🤖 人类主导，AI 协作

本项目把 AI 视为协作式生产系统，而非自主的创意权威。

协作模型建立在若干原则之上：

- 由人类导演定义创意意图并做出最终决策。
- AI 代理在明确范围内执行被委派的任务。
- 研究结论必须保留可追溯的来源。
- 创意提案必须与已确认的决策保持可区分。
- 已批准的体验与可复用的发现可作为项目素材被保存。
- 文件修改与 Git 操作需要明确授权。

项目同时维护决策记录与项目状态文档，以降低长期创意会话中的歧义。

## 🚀 项目原则

1. **体验重于奇观。** 视觉奇观固然重要，但它应服务于有意义的观众体验。
2. **生活重于说教。** 让观众通过亲身经历，去理解一个世界如何运转。
3. **情感重于信息。** 事实让世界可被理解，情感连接让世界被记住。
4. **研究先于虚构。** 尊重原始资料，并清晰标识创意诠释。
5. **批准先于推进。** 在整个开发过程中保持明确的决策边界。
6. **可复用知识重于一次性产出。** 把已批准的发现沉淀为可支撑未来创作的素材。

## 🌍 超越霍格沃茨

HOGWARTS_DAY 以魔法世界作为最初的创作环境。

然而，更大的愿景是：为不同虚构世界创作第一人称体验，发展出一套可复用的方法。

一所魔法学校。
一座未来城市。
一个奇幻王国。
一个只存在于某人想象中的世界。

背后的问题始终如一：

**如果观众能进入这个世界度过一天，是什么会让他们希望永远留下来？**

## 英文摘要

HOGWARTS_DAY 是一套实验性的、可复用的第一人称世界体验叙事工作流。

它把世界研究、观众体验设计、场景开发、导演层面整合与制作复盘，组合成一个结构化的"人机协作"流程。
