## 第1章 研究目标与核心问题

### 1.1 模块1要解决的问题

> **如何从 WF-01 的世界体验、外部灵感、问题和世界机制中发现创意，并把创意的"种子"发展为值得进一步策划的视频概念？**

模块1聚焦"创意从哪来、怎样长大"，**不负责**最终价值取舍（那是模块2）与整体结构（模块3）等（见第9章）。

### 1.2 四个必须区分的对象

| 对象 | 含义 | 说明 |
|---|---|---|
| **主题** | 泛泛的题目方向，如"霍格沃茨的一天""霍格莫德" | 太宽，尚不能拍摄 |
| **素材** | 地点、活动、魔法、物品等原始材料 | 只是"潜在素材"，本身不是创意 |
| **体验** | 观众可能获得的具体感受与参与方式 | 由素材经过体验发现得到 |
| **视频创意** | 可被策划的、有观看承诺与体验组织的完整概念 | 由体验经创意发展与深化得到 |

### 1.3 核心认知

**地点、活动、魔法和物品只是潜在素材。** 它们必须经过：

```
素材 → 体验发现 → 创意发展 → 概念深化 → 完整视频创意
```

才可能成为完整视频创意。**模块1的价值就在于这条"从素材到概念"的转化链**，而不是罗列素材。

## 第2章 创意来源

模块1研究了四类创意来源。四类并用，避免创意枯竭与同质化。

### 2.1 外部灵感输入
从不同领域的作品、创作者和真实案例中寻找**创意机制**（不是表面形式）。参见第4章的案例迁移研究。
> 原则：**不能只复制表面形式**，必须理解其背后的体验机制（见 3.3"世界转译"）。

### 2.2 既有内容再开发
重新审视 WF-01 已经发现的世界体验，寻找**不同视角、不同目标、不同关系、不同组织方式**的可能性。同一素材可以因视角/目标不同而生出不同创意。

### 2.3 问题驱动
从**观众需求**出发——好奇心、情感需求、参与愿望、归属需求、"我想亲自经历"的愿望——反向寻找能回应这些问题的创意机会。

### 2.4 世界机制驱动
从魔法世界**独有的规则、空间、居民、活动和运行方式**出发，发现其他世界难以复制的体验（如移动楼梯的规则、有求必应屋的显现机制、家养小精灵的劳动制度）。这是 HOGWARTS_DAY "世界独特性"的根本来源。

### 2.5 重要边界

> **创意生成不能被 WF-01 已有素材完全限制**，也要允许**原创机会的发现**。模块1允许在 WF-01 素材之外提出原创设想——但必须与"已确认的世界事实"严格区分（见第7章）。

## 第3章 创意发展与深化

保存第一轮研究得到的创意发展思路。

### 3.0 创意发展候选流程（研究候选模型，非正式工作流）

```
创意种子
  → 识别潜力
  → 变形 / 跨领域迁移
  → 形成不同方向
  → 深化概念
  → 导演比较决策
```

> **重要边界**：这是**研究候选模型**，不是已经批准的正式 WF-02 工作流。**不得因为模型包含六个环节，就擅自建立六个 Agent 或六个强制审批节点。** 流程也**不必严格线性执行**（见第8章）。

### 3.1 识别创意潜力

从普通素材中识别可能隐藏的**体验价值**。例：一段"赶去上课"的普通描写，其潜力可能不在"走路"，而在"时间压力下的紧张与如释重负"。识别潜力＝问"这个素材里有没有能让观众想参与/想留下的东西"。

### 3.2 创意变形

**为什么必须真正变形**：只改标题、换场景、换道具，不改变**观众体验的组织方式**，得到的只是"同一个创意的换皮"。真正的变形要改变体验的组织结构。

六种变形方向（每种：改变对象 / 可能的不同体验 / HOGWARTS 应用 / 易误用）：

| # | 变形方向 | 改变的对象 | 可能产生的不同体验 | HOGWARTS 中可能的应用 | 容易出现的误用 |
|---|---|---|---|---|---|
| 1 | **视角变形** | 谁在看、站在谁的位置 | 从"跟着主角看"变为"我就是这个人/这个居民" | 家养小精灵视角看"厨房的那一夜"；画像视角看走廊 | 只换人称，信息与情感入口没变，仍是旁观同一事件 |
| 2 | **目标变形** | 主角要达成什么（观看承诺指向的目标） | 从"打败反派"变为"按时赶到/等一封回信/找个安静角落" | 赶课的时间目标 | 目标换了，但驱动力仍是打斗炫技，目标只是包装 |
| 3 | **机制变形** | 驱动体验运转的规则/引擎（时间限制、失败风险、魔法规则） | 把"看奇观"变成"参与一个有规则的挑战或日常" | 用移动楼梯+时间限制做赶课引擎 | 把普通综艺游戏套魔法皮（表面迁移，见3.3） |
| 4 | **关系变形** | 人物之间的关系结构（师生、同学、主仆、陌生人与居民） | 从"看名人"变为"被当作自己人/被某个居民接纳" | 某个小精灵对学生的善意 | **把复杂制度关系（主仆/奴役）简单可爱化**，抹去张力 |
| 5 | **约束变形** | 附加的限制条件（不能用魔法、只有一晚、不能被发现） | 约束逼出具体动作与紧张/温情 | 深夜不能惊动他人；有求必应屋"只在真正需要时"出现 | 为约束而约束，制造无意义难度 |
| 6 | **形式变形** | 呈现形式（一镜到底、实时、环境音、非叙事陪伴、低事件密度） | 从"剧情"变为"陪伴/在场/氛围" | 《什么也没发生的一天》的低事件密度 | 只换形式标签（如加 ASMR 音轨）而不改变体验组织 |

### 3.3 跨领域迁移（三层）

从外部作品借鉴时，分三个层次：

| 层次 | 迁移的是什么 | 说明 | 风险 |
|---|---|---|---|
| **机制迁移** | "如何组织体验"的机制 | 如借鉴"幻影之旅"的连续移动在场感 | 中 |
| **体验迁移** | "观众获得什么体验" | 如陪伴感、归属、被接纳 | 中 |
| **表达迁移** | 表达手法（镜头、声音、节奏） | 最表层 | **最高**（易沦为表面复制） |

**"世界转译"要求（核心纪律）**：
> 从外部作品借鉴方法时，**必须先理解其背后的体验机制，再将其转化为符合魔法世界规则与生活方式的体验**。
> **不得简单把普通综艺游戏套上魔法元素。**

### 3.4 创意深化（八个深化问题）

用八个问题把一个创意种子"问"成完整视频概念：

| # | 深化问题 | 用途 |
|---|---|---|
| 1 | **核心概念** | 一句话说清"这个视频是什么"——去掉它就散架的那个核 |
| 2 | **观看承诺** | 对观众承诺"你将体验到什么"，后续须兑现 |
| 3 | **体验视角** | 观众以什么身份/视角进入（第一人称学生？精灵？旁观者？） |
| 4 | **核心驱动力** | 推动观看的动力来源（见下方特别说明） |
| 5 | **内容进展** | 体验如何推进（顺序 / 因果 / 变化） |
| 6 | **体验回报** | 观众得到什么（惊叹 / 温暖 / 归属 / 参与感） |
| 7 | **世界价值** | 是否体现这个世界独有、别处不可复制的规则与生活 |
| 8 | **情感余韵** | 结束后留下什么记忆点或情绪 |

> **特别说明（核心驱动力 ≠ 冲突）**：核心驱动力**不一定是冲突**。它也可以来自：
> - **时间**（时间压力、倒计时）
> - **空间探索**（走入未知、寻找路径）
> - **魔法活动**（参与一次施法/酿造/仪式）
> - **生活体验**（过一种日常）
> - **人物关系**（等待、相遇、被接纳）
> - **秘密揭晓**（悬念、发现）
>
> 把驱动力默认等同于"打斗冲突"，是创意单一化的常见原因（见第6章）。

### 4.1 候选机制假说 M1–M4

| 代号 | 机制 | 主要来自 |
|---|---|---|
| **M1** | 在场感 / 第一人称连续移动 | D + A |
| **M2** | 日常事务的细节呈现 | C + B |
| **M3** | 世界自转的微事件（背景自带小动静） | B |

### 4.2 证据边界（必须保留，不得越过）

## 第5章 R-01-TEST-001：项目内创意生成压力测试

用五个真实概念检验"模块1能否产出可用创意"。

### 5.1 五个测试概念

#### 概念 1《还差一次心跳》
- **核心创意**：学生在移动楼梯与肖像之间赶课，在铃声前冲入教室。
- **体验来源**：142 道楼梯、消失台阶、会走的盔甲、皮皮鬼等日常障碍（世界机制驱动）。
- **主要观看驱动力**：时间压力 + 失败风险。
- **可能的体验回报**：紧张后的如释重负、对"学生日常"的代入。
- **测试中发现的优势**：世界底座真实（楼梯、台阶、皮皮鬼等有原文依据），代入感强。
- **测试中发现的问题**：**可能滑向普通跑酷**——若把魔法障碍仅仅当作障碍赛的障碍，就丧失世界独特性。
- **事实 / 推演 / 原创边界**：楼梯/台阶/盔甲/皮皮鬼＝已确认的世界事实（C）；"迟到触发扣分/留堂"的因果＝**合理推演**（制度存在但触发未明文）；冲进教室的具体场景与时间限制引擎＝**原创设想**。

#### 概念 2《一封还没到的信》
- **核心创意**：学生等待一封回信，猫头鹰邮递贯穿一天。
- **体验来源**：猫头鹰邮政的日常（世界机制驱动）。
- **主要观看驱动力**：期待/悬念（信的内容）。
- **可能的体验回报**：连接与被惦记的温暖。
- **测试中发现的优势**：贴合世界日常，有情感线潜力。
- **测试中发现的问题**：**信件动机尚未成熟**——为何等、等谁、为何重要尚未定，驱动偏弱。
- **事实 / 推演 / 原创边界**：猫头鹰邮递日常、礼堂为公共空间＝已确认的世界事实（C）；埃罗尔个体投递差错＝世界事实（**仅个体**，不得推普遍延误）；信件内容、往来对象、晚间查信＝**原创设想**。

#### 概念 3《没人找得到的地方》
- **核心创意**：一个成绩平平、总被忽视的学生三次走过那道墙，进入有求必应屋，屋子为其变出安静学习空间。
- **体验来源**：有求必应屋（七楼、想需求走过三次显现、随需变化）（世界机制驱动）。
- **主要观看驱动力**：归属需求 / 情感回应。
- **可能的体验回报**：被接纳、安全感、"这里为我而存在"。
- **测试中发现的优势**：**把有求必应屋从"奇观设施"转化为"对人的需求的回应"，最值得继续研究。**
- **测试中发现的问题**：须注意楼层（应为七楼而非八楼）；不得把其写成"无限满足/能变出食物"（原著变不出食物）。
- **事实 / 推演 / 原创边界**：有求必应屋机制＝已确认的世界事实（**B 官方补充资料**）；"被忽视学生用它求安静空间"＝合理推演；"差生避风港"定位与具体陈设＝**原创设想**。

#### 概念 4《什么也没发生的一天》
- **核心创意**：反奇观的日常生活，以低事件密度、氛围和陪伴感构成视频体验。
- **体验来源**：霍格沃茨的平凡日常（问题驱动/反奇观）。
- **主要观看驱动力**：陪伴 / 氛围（**偏弱**）。
- **可能的体验回报**：放松、在场感、"想留在这个世界"。
- **测试中发现的优势**：呼应 M2/M3 的"生活感"机制，方向独特。
- **测试中发现的问题**：**存在观看驱动较弱的问题**——缺乏吸引点击与维持观看的钩子。
- **事实 / 推演 / 原创边界**：这是**创作组织方式（原创方法论）**，不是世界命题；不得写成"原著证明霍格沃茨生活就是平淡的"。

#### 概念 5《厨房里的那一夜》
- **核心创意**：从家养小精灵视角观察深夜进入厨房的学生，强调非人居民与温情关系。
- **体验来源**：霍格沃茨厨房（地下、水果画入口、100+ 小精灵、四张长桌）（关系变形+视角变形）。
- **主要观看驱动力**：视角新鲜感 + 温情关系。
- **可能的体验回报**：温情、对非人居民处境的认识。
- **测试中发现的优势**：非人居民视角独特，**具有潜力**。
- **测试中发现的问题**：**必须尊重家养小精灵的制度处境（受魔法束缚、须自罚、无工资等），不能简单可爱化。**
- **事实 / 推演 / 原创边界**：厨房场所与入口机制＝世界事实（C）；家养小精灵群体制度处境＝世界事实（**B 官方补充资料**）；学生深夜进入厨房＝**合理推演**；某个小精灵主动帮助、具体言行互动＝**原创设想**；"个体友善泛化为群体温情"＝**纠错（不成立）**。

### 5.2 测试后得到的判断

- **概念三**：有求必应屋从奇观设施转化为"对人的需求的回应"，**值得继续研究**。
- **概念一**：可能**滑向普通跑酷**。
- **概念二**：信件动机**尚未成熟**。
- **概念四**：存在**观看驱动较弱**的问题。
- **概念五**：具有潜力，但**必须尊重家养小精灵的制度处境，不能简单可爱化**。

### 5.3 创意机会 A–F（压力测试中浮现的六类机会）

| 代号 | 创意机会 | 主要相关概念 |
|---|---|---|
| A | 时间压力 | 概念1 |
| B | 失败与不完美 | 概念1 / 概念2 |
| C | 人物关系 | 概念2 / 概念5 |
| D | 安静归属空间 | 概念3 |
| E | 非人居民视角 | 概念5 |
| F | 反奇观日常 | 概念4 |

### 5.4 测试结论

> **R-01-TEST-001 证明了初步创意生成能力具有一定可用性，但不代表整个方法体系已经完成验证。** 五个概念展示了模块1能产出有潜力的方向，也暴露了明显的失败倾向（跑酷化、驱动弱、动机不成熟、事实越界风险）。

## 第6章 创意生成中的常见失败模式

| # | 失败模式 | 形成原因 | 规避思路 |
|---|---|---|---|
| 1 | **伪多样性** | 看似产生很多创意，实际只是同一创意更换场景或标题 | 用"变形是否改变了体验组织方式"来检验，而非看数量 |
| 2 | **创意堆叠** | 把多个吸引点强行放在一起，却没有统一体验 | 先定义核心概念与观看承诺，再决定取舍 |
| 3 | **过早收敛** | 太早选定一个方向，失去其他有潜力的方案 | 先发散多变体，再交导演比较决策 |
| 4 | **表面迁移** | 复制外部作品的形式，没理解体验机制 | 执行"世界转译"：先懂机制，再翻译成魔法世界 |
| 5 | **事实越界** | 将推演、原创设想写成原著事实 | 用第7章的三分类+A–D 证据等级逐条标注 |
| 6 | **素材依赖** | 只能从已有 WF-01 候选素材产生创意 | 允许外部灵感、问题驱动、世界机制驱动并用；允许原创机会 |
| 7 | **过早评分** | 在创意尚未充分发展时，提前套用单一评分模型 | 创意未深化前不做评分；评分属模块2范畴（见第9章） |

## 第7章 创意生成与事实边界（来自 R-01-REV-001）

事实边界研究是创意生成的**约束与保护机制**，**不是创意生成的全部内容**。它的作用是防止"把推测写成原著事实"，而不是限制创意。

### 7.1 每一条具体主张，区分三种性质

| 主张性质 | 含义 |
|---|---|
| **已确认的世界事实** | 在当前研究证据范围内已获支持、可作为世界事实使用；**不代表直接来自原著**（可能来自官方补充资料） |
| **合理推演** | 原著未明写、但由已知事实可推得；结论状态只能 暂定/待核实/存在争议，**不得标"已确认"** |
| **原创设想** | 项目设计主张；结论固定"非事实主张"，不参与原著事实争议 |

> **分类单位＝每一条具体主张**，不是"整个概念"。一条概念常拆成多条主张，逐条定性质。若一行中含**可分别证实/证伪、或证据来源等级不同**的独立事实，应拆开标注（但不过度细分）。

### 7.2 独立记录证据等级（A–D）

| 等级 | 含义 |
|---|---|
| **A** | 原著原文核验（回到小说原书章节/原句） |
| **B** | 官方补充资料核验（官方百科、官方展览等，非原著原文） |
| **C** | 可靠二手资料（维基、Lexicon、媒体，含引文但非一手） |
| **D** | 摘要级或尚未充分核验 |

### 7.3 主张性质与证据等级是两套不同体系

- **主张性质**回答："这条内容在创作中属于什么性质？"
- **证据等级**回答："目前有什么证据支持这条内容？"
- **二者不得混为一谈**。例：某主张依官方补充资料成立 → 可标"主张性质＝已确认的世界事实；证据等级＝B"，但**不得表述为"原著明确记载"**。

### 7.4 两条硬纪律

1. **不要把官方补充资料伪装成原著原文**（B 不得写成 A / "原著原文核验"）。
2. **不要把合理推演写成明文规则**（"制度存在"≠"某具体触发已被明文规定"）。

### 7.5 事实错误的独立标记

事实错误、来源错配、章节锚点错误、证据不足**不属于三分类中的任何一种**，须用**独立标记**呈现：
- `⚠ 风险提示`：如"来源章节与引文内容不匹配"；
- `✍ 纠错记录`：如"原表述不准确，已删除/修订"；
- `⏳ 待核事项`：如"当前证据不足以确认"。

> 本章内容对应 R-01 v0.3.1，**该版本仍在导演审查阶段**，本章不把其描述为"已正式验收"。

## 第8章 当前研究模型与使用边界

### 8.1 候选创意生成模型

```mermaid
flowchart LR
  A[创意种子] --> B[潜力识别]
  B --> C[创意变形 / 跨领域迁移]
  C --> D[多方向发展]
  D --> E[概念深化<br/>八问]
  E --> F[导演比较决策]
```

### 8.2 使用边界（六条必须说明）

1. 这是**候选研究模型**，不是正式规范。
2. **不代表必须按固定线性顺序执行**（可回溯、可跳步、可迭代）。
3. **不代表需要对应数量的 Agent**（不是六环节=六 Agent）。
4. **不代表模型已经具备完整、稳定的实战能力**。
5. **Agent 应作为创意合作者，而不是自动售货机**——Agent 提供建议、变体、分析，不代替人的判断。
6. **导演保留创意价值取舍与最终方向决定权。**

模块1只负责"产生和发展创意"，**不能替代**后续模块，也**不能自行决定**哪些创意最终入选。

| 模块 | 与模块1的关系 |
|---|---|
| **模块2：体验价值与筛选机制** | 模块1负责产生和发展创意；模块2研究如何判断这些体验/创意是否值得选择。**模块1不能自行决定最终入选。** |
| **模块3：体验组合与整体结构** | 模块1可产生多个方向；模块3研究体验之间的互补、重复、冲突、递进与整体结构。 |
| **模块4：观众注意力与体验兑现** | 模块1提出观看承诺与体验概念；模块4研究如何让观众持续投入、如何兑现承诺。 |
| **模块5：制作约束与质量验证** | 模块1允许探索"有潜力但制作困难"的创意；模块5负责 AI 实现能力、连续性、成本、失败风险与质量门槛。 |
| **模块6：整合、案例验证与方法迁移** | 最终通过真实 WF-01 体验与项目创作案例检验各模块方法。 |

> **模块1不能替代这些后续研究。** 模块间是分工，不是升级链。
